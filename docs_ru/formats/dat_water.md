# `water.dat` — кадры анимированной нормальной карты воды

- **Архив**: `Textures.vfs` (1 файл: `water.dat`, 741 388 байт).
- **Загрузчик**: `CGeometryWaterData::CGeometryWaterData(CRenderer *,
  TWaterGeometries::iterator, CStringReader &)` —
  `Game/Renderers/D3D9/GeometryWaterData.cpp:4`.
- **Точка входа загрузки**: `CRenderer::CreateWaterGeometry()`
  (`Renderer.cpp:4571`).

---

## 1. Назначение

`water.dat` — **циклический стек кадров карты высот**, который движок
преобразует в стек текстур-нормалей на этапе загрузки. Рендерящаяся
поверхность воды (`IGeometryWater`) сэмплирует текущий кадр на каждом
тике, получая бегущие нормали. Это единственный `.dat`-файл в
`Textures.vfs`, и он не связан с `Strings.vfs/main.dat`
(см. [dat_strings.md](dat_strings.md)).

---

## 2. Раскладка на диске

```
+----------------------------+
| u32  m_ulSeq               |   число кадров в цикле
| u32  m_ulWidth             |   ширина одного кадра в пикселях
| u32  m_ulHeight            |   высота одного кадра в пикселях
+----------------------------+
| u8[m_ulSeq][m_ulHeight][m_ulWidth]   сырые кадры карты высот
+----------------------------+
```

Каждый байт — значение высоты в диапазоне [0, 255]. Без выравнивания, без
покадрового заголовка. Загрузчик потребляет весь поток последовательно
(`GeometryWaterData.cpp:9-11`):

```cpp
reader >> m_ulSeq >> m_ulWidth >> m_ulHeight;
for (i = 0; i < m_ulSeq; ++i, reader.Skip(m_ulWidth * m_ulHeight)) {
    …convert this frame to a normal-map…
}
```

Для поставочного файла размеры подразумевают примерно
`(741 388 − 12) / (W·H·Seq)` байт-бюджет на кадр. Точная тройка W×H×Seq
закодирована в первых 12 байтах; их можно прочитать напрямую, чтобы
получить точное количество.

---

## 3. Преобразование высоты в нормаль (на этапе загрузки)

Для каждого пикселя `(x, y)` кадра загрузчик выполняет `CALC_WATER`
(`GeometryWaterData.cpp:51`):

```c
float nx = (long)height[x-1, y] - (long)height[x+1, y];   // ∂h/∂x
float ny = (long)height[x, y-1] - (long)height[x, y+1];   // ∂h/∂y
float l  = length(nx, 150, ny);                            // 3D length
DWORD r  = ((nx/l)/2 + 0.5) * 255;                         // → 0..255
DWORD g  = ((150/l)/2 + 0.5) * 255;
DWORD b  = ((ny/l)/2 + 0.5) * 255;
dest_pixel = (b << 16) | (g << 8) | r;                     // X8R8G8B8
```

- Индексы строки и столбца оборачиваются (верхняя строка использует
  нижнюю строку в качестве «предыдущей» и т. д.), давая бесшовно тайлящиеся
  карты нормалей.
- Жёстко прошитое `150` — это весовой коэффициент оси вверх: большие
  значения делают поверхность воды более плоской; меньшие — более
  бугристой. Выбор — это визуальная константа.
- Результат сохраняется как `D3DFMT_X8R8G8B8` (32-битный `B8G8R8X8` в
  памяти).

После преобразования исходные байты карты высот отбрасываются —
сохраняются только полученные текстуры.

## 4. Сжатие

**Нет.** Весь файл — сырые байты, отображаемые в память из
`Textures.vfs` и обходимые один раз при загрузке.
