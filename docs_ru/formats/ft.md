# `.ft` — растровый шрифт

- **Архив**: `Fonts.vfs` (10 файлов).
- **Примеры**: `arial_10_cyr.ft`, `arial_12_cyr.ft`, `arial_14_cyr.ft`,
  `console.ft`.
- **Загрузчик**: `CBitmapFont::CBitmapFont(CRenderer *, ..., IMMLoadObject *)` —
  `Game/Renderers/D3D9/BitmapFont.cpp:18`.
- **Владеющий интерфейс**: `IRFont` (хэндл шрифта на стороне рендера).
- **Фабрика**: `CRenderer::CFontFactory::CreateBitmapFont(strFileName)`.
- **Инструмент авторинга**: `SRC/PlagueCity/tools/FontGen/` (внутренний
  GUI-сборщик шрифтов альфы). Более новый ребилд в `tools/FontGenNew/`
  выдаёт ту же раскладку на диске.

---

## 1. Раскладка на диске

```
+-------------------------------+
| u32  m_dwTextHeight           |   высота от базовой линии до базовой линии
| u32  m_dwHeight               |   число строк битмапа на ячейку глифа
| u32  ulCharCount              |   число записей глифов
+-------------------------------+
| CHAR_RECORD[ulCharCount]      |   метаданные, см. 1.1
+-------------------------------+
| u32  ulPairCount              |   число записей кернинга
+-------------------------------+
| KERN_RECORD[ulPairCount]      |   см. 1.2
+-------------------------------+
| BITMAP_BLOB                   |   сырые альфа-битмапы глифов
|   per glyph (in record order):|
|     u8[m_dwHeight × m_dwWidth]|   построчно, 1 байт = альфа 0..255
+-------------------------------+
```

После разбора записей глифов загрузчик запоминает смещение начала блоба
битмапов в файле (`dwLastOffset = reader.GetSeekPos()`,
`BitmapFont.cpp:54`) и **лениво загружает** глифы в runtime-атлас
текстур. Блоб битмапов никогда не читается в память целиком — страницы
на диске подгружаются в атлас по требованию при первом использовании.

### 1.1 `CHAR_RECORD` (на глиф)

```
wchar     c              // кодпоинт Unicode (UTF-16, little-endian)
u32       m_dwWidth      // ширина глифа в пикселях в блобе битмапов
CIVector2 m_vOffset      // 8 байт (i32 x, i32 y) — смещение пера к началу
i32       m_lAdvance     // смещение пера после отрисовки этого глифа
```

Структура читается поле за полем через перегрузки `>>`
(`BitmapFont.cpp:33-35`). Высота битмапа — общая `m_dwHeight`,
объявленная выше; на глиф варьируется только ширина (шрифт переменной
ширины).

Смещение глифа в файле для ленивого загрузчика вычисляется как сумма:

```
glyph[0].fileOffset = blob_start
glyph[i].fileOffset = glyph[i-1].fileOffset + glyph[i-1].m_dwWidth * m_dwHeight
```

### 1.2 `KERN_RECORD`

```
wchar  c1
wchar  c2
i32    lAmount       // знаковая корректировка кернинга в пикселях, когда за c1 идёт c2
```

Плоский список, ключом является пара символов; во время выполнения
строится `std::map<pair<wchar_t, wchar_t>, int>` для поиска
(`BitmapFont.cpp:52`).

---

## 2. Кодировка

- Все числовые значения little-endian.
- `wchar_t` в Windows MSVC — **16-битный UTF-16LE**, поэтому каждая
  запись символа использует 2 байта на кодпоинт.
- В заголовке файла **нет байта кодировки** — шрифт неявно Unicode.
- Наличие `?` (U+003F) **гарантируется ассертом** в загрузчике:
  `m_Characters[CHARCODE_UNKNOWN]` обязан существовать, иначе `ASSERT`
  срабатывает (`BitmapFont.cpp:44`). Это запасной глиф для неизвестных
  символов.

---

## 3. Runtime-атлас

После загрузки движок:

1. Выбирает пиксельный формат атласа: P8, если GPU поддерживает
   `D3DFMT_P8` + palettised alpha, иначе `A8L8`, иначе
   `A8R8G8B8`. Выбранный размер текселя записан в `m_dwTexelStride`
   (1, 2 или 4 байта) — `BitmapFont.cpp:66-77`.
2. Вычисляет степенно-двойной размер атласа как
   `ceil(sqrt(area / (rowHeight + 2)) × 1.1)`.
3. Аллоцирует атлас как одну большую текстуру из managed-пула
   (`m_idTexture`).
4. Добавляет себя в «discardable»-список рендера — при потере
   устройства атлас может быть перегенерирован «на лету» из файла на
   диске.

Глифы заносятся в атлас **построчным упаковщиком снизу вверх**
(`m_RowSpace` отслеживает оставшуюся ширину на каждой строке), а старые
глифы вытесняются по LRU, когда в атласе заканчивается место. Результат —
классический динамический атлас шрифтов, в котором файл `.ft` служит
**постоянным источником истины**.

---

## 4. Сжатие

**Нет.** Битмапы глифов — несжатая 8-битная альфа. Размер файла обычно
25 КБ на шрифт (10 × ~25 КБ ≈ 250 КБ в сумме в
`Fonts.vfs`).

  и использует библиотеку FreeType в
  `SRC/PlagueCity/tools/FontGen/FontRendererFT.cpp` для создания этих
  битмапов из системных TTF.
