# `.lsh` — лицевая модель LifeStudio HEAD

- **Архив**: `Geometries.vfs` (29 файлов; по одному на голову главного персонажа).
- **Примеры**: `rubin_2.lsh`, `andrei.lsh`, `aglaja.lsh`, `klara.lsh` …
- **Загрузчик**: `CLSHead::CASCache::CreateInstance()` в
  `Game/Game/LSHead.cpp:30`. Разбор формата делегируется проприетарному
  **LifeStudio HEAD 2.5 SDK** (`tools/LifeStudioHeadAPIS.dll`).
- **Владеющие интерфейсы**: `IRLSHead` (сторона рендера) + `ILSHeadData`
  (сторона данных). Высокоуровневый `IGeometryLSHead` подключает голову LS
  в конвейер геометрии.

---

## 1. Что такое `.lsh`

`.lsh` — это **модель головы + лицевой риг** для синхронизации губ
персонажа, слежения глаз, морфов моргания/улыбки/нахмуривания и
процедурной мышечной деформации. Это бинарная сериализованная форма
класса SDK `IMMTree` — иерархического «дерева макромышц».

У каждого персонажа не более одного `.lsh` (плюс по одному
[`.mma`](mma.md) и [`.mms`](mms.md) для кривых анимации и данных
секвенсера, и по одному [`.hand`](hand.md) для прикреплённого меша
руки, держащей оружие). 29 файлов `.lsh` зеркально соответствуют 29
именованным головам NPC с диалоговыми репликами.

---

## 2. Раскладка на диске — непрозрачна для исходников движка

Движок трактует тело файла как **непрозрачный блоб**, передаваемый
напрямую в SDK:

```cpp
// LSHead.cpp ~30 (paraphrased)
release_ptr<IMMLoadObject> pLoad(pFS->CreateMappedLoadObject(strLSHName));
LifeStudioHeadAPI::IMMTree *pTree;
pTree->Load(pLoad->GetMemoryPointer(), pLoad->GetSize());
```

Раскладка байтов не раскрыта в открытом дереве исходников Pathologic.
SDK поставляется только как закрытый `LifeStudioHeadAPIS.dll`. Что
известно из заголовка `Game/LSHead/h/LifeStudioHeadAPI.h` и того, как
движок использует результат:

| Концепция              | Использование движком                                   |
|------------------------|---------------------------------------------------------|
| Меш черепа             | Базовый треугольный меш, та же философия формата, что и `.mesh`. |
| Вершина кожи           | Позиция + 1–N весов мышц.                               |
| Макромышца             | Деформатор, похожий на кость, с OBB влияния.            |
| Дескриптор зрачка/радужки | Прямоугольник текстуры + опорная точка на каждый глаз. Управляет `UVPupil.dll`. |
| Блендшейп / морф       | Массив дельта-вершин с индексами (загружается из `.mma`). |
| Связка с секвенсером   | Имена таймлайнов, ключевание которых выполняет `.mms`.   |
| Локаторы               | Именованные точки крепления (левый глаз, правый глаз, челюсть, …). |

Заголовочный файл объявляет фиксированную точку входа C-API, которую
вызывает движок. Внутренняя бинарная структура — **частная вендорская**
и Lifestudio её не публиковала.

## 3. Последовательность загрузки внутри движка

`CLSHead::Load()` (LSHead.cpp:90+) — оркестратор. Для головы LS каждого
персонажа он загружает три файла в этом порядке:

1. `<name>.lsh` — модель головы (этот файл).
2. `<name>.mma` — кривые морф-анимации (см. [mma.md](mma.md)).
3. `<name>.mms` — файл секвенсера (см. [mms.md](mms.md)).

Затем они **сшиваются** через `pTree->AttachAnimation()` и
`pTree->AttachSequencer()`, образуя единый риг в памяти, который рендер
запрашивает каждый кадр.

```
.lsh  ── geometry + muscles ──┐
.mma  ── morph keyframes     ─┤──→ IMMTree (in memory)  ──→ IRLSHead
.mms  ── sequencer timeline  ─┘
```

Аудио управляет секвенсером `mms` через систему диалогов
(`UIDialogContext.cpp`), которая продвигает веса морфов каждый кадр;
результат рендерится в `GeometryLSHeadData.cpp`.

## 4. Внешние инструменты

- Редактирование выполнялось в инструменте авторинга LifeStudio HEAD
  (пакет плагинов для Maya/Max, **отсутствующий** в этом исходниковом дропе).
- `tools/LifeStudioHeadAPIS.dll` — runtime-парсер; он **не** имеет
  документированной раскладки заголовка в открытом коде.
- `tools/UVPupil.dll` выполняет проход деформации радужки во время
  рендера.

Для целей реверс-инжиниринга формат лучше всего рассматривать как **чёрный
ящик**: за пределами SDK нет первородного импортёра/экспортёра.
Эмпирический анализ байтового шаблона заголовка `.lsh` потребуется, если
вам нужно его модифицировать.

## 5. Перекрёстные ссылки

- [`.mma`](mma.md) и [`.mms`](mms.md) — файлы-компаньоны; сам по себе
  `.lsh` ничего наблюдаемого не делает.
- [`.hand`](hand.md) — отдельный меш на каждого персонажа, идущий рядом
  — он **не** является частью самой LS-головы, но загружается тем же
  объектом `CLSHead` для удобства.
- Текстуры персонажа (кожа, глаз, волос) находятся в `Textures.vfs` как
  `.tex` / `.png` — см. [tex.md](tex.md), [png_tga.md](png_tga.md).
