# `.mma` — кривые морф-анимации LifeStudio

- **Архив**: `Geometries.vfs` (1 файл: `klara.mma`).
- **Владелец**: `LifeStudioHeadAPI::IMMAnimation` (закрытый SDK).
- **Загружается**: `CLSHead::CASCache::CreateInstance()` →
  `LifeStudioHeadAPI::IMMAnimation::Load(...)` (`Game/Game/LSHead.cpp` ~149).

---

## 1. Назначение

`.mma` содержит **кривые анимации** для морф-таргетов, определённых в
соответствующем файле головы [`.lsh`](lsh.md). По одному `.mma` на персонажа.
Кривые описывают веса морфов по кадрам для глаз (моргание, направление взгляда),
бровей (поднятие, сведение), губ (улыбка, гримаса, надутые губы, открытие
челюсти) и любых пользовательских каналов выражений, заданных в LifeStudio.

`klara.mma` — единственный поставляемый файл, потому что Клара — единственный
персонаж в альфа-сборке, у кого есть полностью предзаписанная лицевая
кинематика. Остальные персонажи синхронизируют губы процедурно и используют
лишь ключевые морфы, запечённые в самом `.lsh`.

---

## 2. Раскладка на диске — непрозрачная

Ситуация идентична [`.lsh`](lsh.md): формат — приватный бинарь SDK,
сериализованный LifeStudio HEAD 2.5. Движок обращается с телом файла как с
непрозрачным блобом.

Что можно вывести из того, как движок использует получаемый объект:

| Concept                | Engine API call           |
|------------------------|--------------------------|
| Animation registration | `IMMTree::AttachAnimation(IMMAnimation*, name)` |
| Time-base resolution   | Float-second timeline scrubbed each frame |
| Channel count          | Equals the number of morph targets in the matching `.lsh` |
| Curve representation   | Per-channel keyframe array — interpolation handled by SDK |

SDK предоставляет `Play()`, `Stop()`, `SetWeight()` и `Update(dt)` на объекте
анимации — публичного метода для байтовой раскладки нет.

---

## 3. Сжатие

Неизвестно / непрозрачно. Файл маленький (≈ 120 КБ), и `IMMLoadObject` движка
просто отображает его в память и передаёт указатель SDK.

---

## 4. Связанные форматы

- [`.lsh`](lsh.md) — модель головы и риг, который анимируют кривые `.mma`.
- [`.mms`](mms.md) — **секвенсор**, который оркестрирует, какие анимации
  `.mma` проигрывать и когда. `.mma` — это данные; `.mms` — это скрипт,
  который на них ссылается.

---

## 5. Итог

Если вы хотите модифицировать `klara.mma`, без авторского инструмента
LifeStudio HEAD 2.5 (или тщательного реверса
`tools/LifeStudioHeadAPIS.dll`) этого сделать нельзя. Для всех остальных —
относитесь к нему как к непрозрачному ассету и держите рядом с
соответствующими `.lsh` и `.mms` в `Geometries.vfs`.
